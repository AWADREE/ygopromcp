YGOPro Windows package: card data setup

This archive includes the client, its Windows GNU/UCRT64 DLLs, the original
neutral UI textures and Noto Sans CJK fonts, the original Gilded theme, and
required license notices. It excludes card databases, card artwork, card
effect scripts, personal decks, replays, local settings, and diagnostics.

The included fallback textures and fonts are sufficient for basic UI loading.
A compatible card-data set is separate:
  cards.cdb
  strings.conf
  script\constant.lua and the matching card effect scripts

Double-click "Play YGOPro.cmd". On a clean first run, the native launcher
offers to download the pinned compatible card database and scripts. It checks
their hashes before installation and leaves existing personal data untouched.
Canceling leaves the folder ready for another attempt. Existing unverified
game data requires an explicit choice and is never overwritten automatically.
Card artwork is separate and is not downloaded by this setup.

After first-run setup, use "MCP YGOPro.cmd" as an MCP stdio client's command,
with this directory as its working directory. That command passes --mcp to
the native launcher and reserves stdout for JSON-RPC. The optional in-game
localhost HTTP MCP control is configured separately on the home screen.
One MCP client owns one process. See MANIFEST.json for exact package hashes,
source revision, and the pinned original fallback asset manifest.
