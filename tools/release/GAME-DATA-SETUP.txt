YGOPro Windows package: card data setup

This archive includes the client, its Windows GNU/UCRT64 DLLs, the original
neutral UI textures and Noto Sans CJK fonts, the original Gilded theme, and
required license notices. It excludes card databases, card artwork, card
effect scripts, personal decks, replays, local settings, and diagnostics.

The included fallback textures and fonts are sufficient for basic UI loading.
A compatible card-data set is separate:
  cards.cdb
  strings.conf
  script\constant.lua and the matching card effect scripts

Use the release's reviewed first-run setup when available. Otherwise, supply
compatible, lawfully obtained card data from your own installation. Keep
personal deck\, replay\, expansions\, and system.conf in your own runtime.
Do not silently substitute an unrelated database or set of card scripts.

Double-click "Play YGOPro.cmd" to play. For an MCP stdio client, configure
"MCP YGOPro.cmd" as the command with this directory as its working directory.
One MCP client owns one process. See MANIFEST.json for exact package hashes,
source revision, and the pinned original fallback asset manifest.
